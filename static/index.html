FAQ

Preguntas frecuentes

¿Qué plataformas soporta Velo?

Velo utiliza yt-dlp como motor principal de extracción, lo que le permite trabajar con más de 1000 sitios web incluyendo YouTube, Vimeo, Twitter/X, Instagram, TikTok, Facebook, Dailymotion, Twitch, SoundCloud y muchos más.

¿Cómo funcionan las descargas masivas o de playlists?

Al seleccionar la pestaña "Lista / Playlist", puedes ingresar múltiples URLs o el enlace de una lista completa. Velo procesa cada elemento en el servidor y te entrega un único archivo comprimido .ZIP listo para guardar.

¿Puedo recortar solo un fragmento de un video?

Sí. Activa la opción de recorte en las opciones avanzadas para usar el deslizador interactivo o los botones de atajo (15s, 30s, 60s). Velo cortará el video o audio de forma exacta sin descargar datos innecesarios.

¿Cómo descargo solo los subtítulos de un video?

En el panel de opciones avanzadas se detectan los subtítulos disponibles (manuales o auto-generados). Puedes seleccionar el idioma y exportar el archivo directamente en formato .SRT, .VTT o .TXT.

¿Velo almacena mis descargas o datos personales?

No. Los archivos se procesan de forma temporal en el servidor durante la transferencia y se eliminan de forma inmediata. No se recopilan datos personales, historial de uso ni cookies de rastreo.
